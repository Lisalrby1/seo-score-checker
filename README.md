# SEO Score Checker

A simple and responsive SEO tool for checking website Domain Authority (DA), Page Authority (PA), and Spam Score.

## Features

- Domain Authority (DA)
- Page Authority (PA)
- Spam Score (SS)
- Website URL input
- Responsive design
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
seo-score-checker/
│
├── index.html

```

## How to Use

1. Open the SEO Score Checker.
2. Enter a website URL.
3. Enter the DA, PA, and Spam Score values.
4. Click the check button.
5. View the results.

## Important Note

DA, PA, and Spam Score are proprietary SEO metrics. A real-time checker requires an appropriate SEO data API. This project currently provides the frontend interface for displaying SEO metrics.
